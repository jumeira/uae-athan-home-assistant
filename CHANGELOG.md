# Changelog

## 0.3.0 - 2026-09-28

- Accept the IACAD perpetual table only for Dubai City, Rural Dubai, and Hatta.
- Keep all other areas strictly locked to the Jumeirapps v2 calculation engine.
- Validate top-level mixed catalogue metadata and per-day source metadata.
- Add source-policy regression tests and the Home Assistant `strings.json` source.
- Add complete HACS publishing metadata for the planned public repository.

## 0.2.0 - 2026-09-25

- Require the Jumeirapps calculated v2 provider and reject unexpected sources.
- Add Arabic and English setup, options, entity, and action translations.
- Allow changing the area and selecting Fajr and general Athan recordings.
- Add next-prayer and next-prayer-time sensors.
- Add refresh and prayer-event test actions.
- Add local Home Assistant brand images and HACS metadata.
- Add release validation and deterministic ZIP packaging.

## 0.1.0 - 2026-09-17

- Initial custom integration with prayer sensors and scheduled prayer events.
