# بنية تكامل Home Assistant لأذان الإمارات

## الهدف

توفير تكامل Home Assistant مستقل لتشغيل أتمتة الأذان داخل المنزل، بنفس مصدر
البيانات المستخدم في تطبيق Homey، ومن دون وضع أي مفاتيح أو روابط رسمية داخل
بيئة المستخدم.

## تدفق البيانات

```text
Home Assistant
  -> Jumeirapps UAE Athan API
    -> جدول IACAD الدائم لمناطق دبي الثلاث
    -> محرك uae_praytimes_evidence_v2 للمناطق العشر الأخرى
```

نقاط Jumeirapps المستخدمة:

- `areas.php`: قائمة المناطق.
- `prayer-times.php`: مواقيت الصلاة لنطاق زمني.
- `athan-settings.php`: إعدادات الأذان ومكتبة الروابط الصوتية.

## مكونات التكامل

- `manifest.json`: تعريف التكامل كـ custom integration.
- `config_flow.py`: الإعداد من الواجهة واختيار المنطقة.
- `api.py`: عميل HTTP لوسيط Jumeirapps.
- `coordinator.py`: تحديث دوري وكاش بيانات الصلاة.
- `sensor.py`: حساسات الصلاة القادمة وأوقات الصلوات الخمس.
- `__init__.py`: تحميل التكامل وجدولة أحداث الأذان.

## الحدث

اسم الحدث:

```text
uae_athan_event
```

يطلق مرة واحدة عند دخول وقت الصلاة المجدول، ويحتوي على:

- الصلاة.
- التاريخ.
- الوقت.
- المنطقة.
- مصدر البيانات.
- رابط ملف الأذان إذا كان متوفراً في مكتبة الصوتيات.

## منع تكرار الأذان

يعتمد التكامل على جدولة نقطة زمنية واحدة لكل صلاة باستخدام بيانات الكاش الحالية.
عند وصول تحديث جديد، يلغي الجداول القديمة ويعيد بناءها للصلوات المستقبلية فقط.
بهذا لا يعاد إطلاق صلاة مضت، ولا يبقى مؤقت قديم بعد تغير البيانات.

## لماذا لا يستدعي جهاز المستخدم المصدر الحكومي؟

لأن قرار المشروع الحالي هو أن جهاز المستخدم لا يتصل إلا بخدمة Jumeirapps. هذا
يحافظ على فصل المسؤوليات:

- جميرابس تطبق سياسة المصدر المعتمدة وتحدّثها مركزياً.
- Home Assistant يقرأ بيانات جاهزة وخفيفة.
- لا توجد مفاتيح رسمية أو شروط استخدام حكومية داخل جهاز المستخدم.

## قفل المصدر حسب المنطقة

لا يكتفي التكامل بنجاح طلب HTTP. استجابات قائمة المناطق والصوتيات يجب أن تعلن
الوضع المختلط والمزودين المسموحين ومناطق الجدول الدائم. وبعد اختيار المنطقة
يطبق التكامل إحدى السياستين التاليتين:

```text
Dubai City / Rural Dubai / Hatta
  provider = IACAD
  mode     = perpetual_table
  table    = perpetual_gregorian

All other areas
  provider = JUMEIRAPPS_CALCULATED
  method   = uae_praytimes_evidence_v2
  mode     = calculated
```

ويتحقق أيضاً من معلومات المصدر والتوليد داخل كل يوم. إذا تغيرت أي قيمة، يرفض
التكامل الاستجابة ويعرض خطأ تحديث بدلاً من قبول مصدر مختلف بصمت.

## اختيار الصوت

يختار المستخدم تسجيلاً للفجر وتسجيلاً لبقية الصلوات. لا يشغّل التكامل الصوت
بنفسه، بل يضع الرابط في `uae_athan_event` حتى تستخدمه أتمتة Home Assistant مع
Sonos أو أي `media_player` متوافق.
